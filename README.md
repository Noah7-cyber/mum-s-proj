## 📌 Project Overview
This modern, high-converting landing page was built for **TIKENOD VENTURES** (Barnawa GRA, Kaduna), Nigeria’s premier distributor of tailoring supplies, luxury fabrics, lace trims, zippers, sewing threads, interfacings, and sewing accessories.

The website incorporates the official **GInvoice Storefront** (`https://ginvoice.com.ng/c/tikenod-ventures`) directly into the customer journey, showcases all **1,730+ live catalogued products**, provides an **interactive Order Bag with WhatsApp checkout**, and includes a **dedicated GInvoice Advertisement & SME Growth Spotlight** to help other Nigerian vendors launch their own digital storefronts.

---

## 🚀 Key Features

1. **GInvoice Storefront Integration:**
   - Every product card, header, and call-to-action is integrated with [ginvoice.com.ng/c/tikenod-ventures](https://ginvoice.com.ng/c/tikenod-ventures).
   - Real-time stock status, pricing in Nigerian Naira (₦), and store verification badges.

2. **Full Product Catalogue (1,730 Items):**
   - Instant client-side search across 1,730 products with zero latency.
   - Categorized by 8 departments:
     - **Zippers & Sliders** (391 items)
     - **Fabrics & Linings** (333 items)
     - **Laces & Trims** (224 items)
     - **Threads & Cones** (115 items)
     - **Buttons & Fasteners** (63 items)
     - **Packaging & Tools** (36 items)
     - **Gums & Interfacings** (27 items)
     - **Haberdashery & Accessories** (541 items)
   - Sort by Price (Low/High), Product Name, or Stock availability.
   - Filter by "In-Stock Only".

3. **Interactive Slide-Out Order Bag (Cart Drawer):**
   - Customers can add items to their bag with live quantity adjustment.
   - Computes total estimated price in ₦.
   - Generates an itemized, pre-formatted order message and launches **WhatsApp** (`+234 805 347 2434`) with one click.
   - Direct button to checkout on GInvoice storefront.

4. **Dedicated GInvoice Advertisement & Feature Spotlight:**

## 💻 How to View & Test Locally

Simply open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

Alternatively, you can run a local HTTP server:

```bash
# Using Python
python -m http.server 8000

# Open http://localhost:8000 in your browser
```

## 🌐 Deploying to the Web

You can host this website in seconds on:
- **GitHub Pages:** Push to a repository and enable GitHub Pages in repository settings.
- **Netlify / Vercel:** Drag and drop the `teknod` folder into Netlify Drop or Vercel dashboard.
- **Custom Web Server:** Upload all files via cPanel / FTP to public_html.
